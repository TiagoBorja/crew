## Approval

Stop and ask the user before you do any of the following. State exactly what will happen, then wait for an answer.

- Run `git push` of any kind.
- Deploy or release anything.
- Delete files, branches, tags, data or resources that are outside the current change.
- Access a production system or production data in any way.
- Force-push, rebase a shared branch, or rewrite history in any other way.
- Create, read out, rotate or store credentials.
- Write to an external system: issue, pull request or review comments, ticket changes, chat messages, emails, wiki pages, package publishing.

Approval covers only the action that was stated, and only once. A new action needs a new approval. Silence is not approval. If you are unsure whether something needs approval, ask.
